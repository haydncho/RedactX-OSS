数据格式
请求为 multipart/form-data 或查询参数；响应为 JSON、PDF 或图片

认证

服务端设置了环境变量 REDACTX_API_KEY 时，除 /v1/health 外的所有接口都要带请求头 X-API-Key，否则返回 401。未设置时无需认证。服务默认只绑定本机回环地址。

错误格式

出错时返回对应的 HTTP 状态码，响应体统一为：

{"error": {"code": "NOT_FOUND", "message": "任务不存在或已过期删除"}}
状态码code含义
400INVALID_FILE INVALID_OPTIONS CONVERT_FAILED 等文件无法识别、选项不合法、文档转换失败、加密 PDF 密码错误
401BAD_API_KEYAPI Key 缺失或不正确
404NOT_FOUND任务、报告或预览不存在（可能已到期删除）
409NOT_READY BUSY任务尚未完成；或正在处理，暂不能删除
413TOO_LARGE超出上传大小、页数上限，或同步接口的 10 页 / 20 MB 限制

options 字段

POST /v1/jobs 与 POST /v1/redact 的 options 表单字段是一个 JSON 字符串，所有字段都可省略。

字段类型默认说明
