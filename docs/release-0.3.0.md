# 0.3.0 正式发布

发布日期：2026-11-08。

本次将已验收的 0.3.0rc1 迁移成果发布为 0.3.0，对外服务启用印章、签名视觉检测。自部署仍默认关闭，启用方法见 [视觉模型说明](visual-model.md)。模型文件独立准备，不随 Git 仓库或源码包分发。

## 功能与兼容

- 在原件去水印前运行 RF-DETR 全页与分块检测，覆盖文字层 PDF 及扫描件。
- 对最终输出重新检查视觉残留；日期冲突保留日期并提示复核。
- 人工修改遮盖框后更新视觉检查，旧文字检查证据标记失效。
- 异步任务、同步响应头、报告和网页呈现视觉检查状态；兼容 drg-oras 的提交、轮询、报告、预览、改框和结果读取。
- 修正多页 TIFF 异常低分辨率的处理。

## 验证与限制

正式版回归 156 项测试全部通过。14 页候选版合成对比中，258 项应遮内容全部覆盖，106 项应保留内容未误遮；另有灰章补检样例及 20 页容器运行验证。详见 [验收记录](visual-acceptance-2026-11-07.md) 与 [候选版升级记录](visual-upgrade-2026-11-07.md)。

上述样本均为合成数据，尚无真实临床样本准确率结论。视觉模型增加处理耗时，仍可能漏检或混淆印章、签名类别；疑似残留和日期冲突应人工复核。
