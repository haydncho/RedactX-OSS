# 标注规范

用于训练手写区与签名检测模型、正文人名识别（NER）模型的标注工作。标注在锐消 RedactX 的复核台上完成，导出为 COCO 格式。

## 1. 数据与环境

- 只使用已获书面授权的病案样本；授权范围、保管人、销毁期限以授权文件为准。
- 标注机与服务都不联网。服务以 `REDACTX_ALLOW_EXPORT=1` 启动时才能导出标注，并且必须同时设置 `REDACTX_API_KEY`，否则导出接口拒绝服务。服务只支持一个 Key：只发给本批标注人员，每批结束后更换。只在标注环境里打开，平时的脱敏服务不要设置。
- 每次导出都记入数据目录下的 `export-audit.log`：时间、任务编号、页数、框数，不含任何内容。定期与样本台账核对。
- 提交样本时勾选“保留原件以便复核”：复核台上才能删框、改框，也才能导出打码前的原始页面。
- 导出的压缩包含真实病案内容。存放在授权的加密位置，不拷贝到个人设备，不通过网盘、即时通讯传输。
- 标注完成、导出之后，点“完成复核”删除服务上保留的原始页面；任务到期也会自动删除。

## 2. 流程

1. 管理员按批次提交样本（每批 20–50 份），结果保留时长按标注进度设置。
2. 标注员逐页打开“复核”：
   - 漏遮的：拖出新框，选对类型；
   - 多遮、框偏的：点选后删除，或拖动、拉伸到位。
   - 改类型：点选框后，在“所选框类型”里换一个。
   - 快捷键（鼠标移到复核条上的“快捷键”可查看）：
     - `Tab` / `Shift+Tab`：切换本页的框；
     - `[` / `]`：切换类型；
     - 方向键：微调所选框，按住 `Shift` 移动 10 像素；
     - `Delete`：删除所选框；`Esc`：取消选择；
     - `⌘/Ctrl + S`：保存并重新打码。
   - 有未保存修改的页，缩略图右上角有橙色圆点。
3. 保存并重新打码后，点“导出标注”，得到 `annotations-<任务>.zip`：
   - `images/page-0001.jpg` 等：打码前的原始页面；
   - `annotations.json`：COCO 格式。`bbox` 为像素坐标 `[x, y, 宽, 高]`，`category_id` 对应 `categories` 里的实体类型。
4. 质检（见第 5 节）通过后点“完成复核”。

## 3. 类别

检测模型只用下面几类。框的类型与复核台下拉框里的名称一致。

| 类型 | 名称 | 框什么 |
|---|---|---|
| `SIGNATURE` | 签名 | 手写签名的全部笔画，含收笔拖尾、签在格子外的部分；一格多人签名框在一起 |
| `HANDWRITTEN_FIELD` | 手写填写区 | 表单字段后的手写内容（姓名、号码、地址等），只框笔迹，不含印刷的字段名 |
| `SEAL` | 印章 | 整个章的外圈；淡色章、残缺章也框 |
| `LOGO` | Logo | 医院标识图形，不含旁边的院名文字 |
| `QRCODE` | 二维码与条码 | 码的外框，含静区 |

文字类（姓名、证件号、电话、地址、机构名等）照常用复核台的类型标出，供核对规则与 NER。

- 手写姓名同时标两个框也可以：`HANDWRITTEN_FIELD` 或 `SIGNATURE` 框笔迹，外加一个 `PERSON` 或 `STAFF` 框。
- 印刷的姓名只标 `PERSON` 或 `STAFF`。

## 4. 框的规则

- 贴合笔迹或图形的外接矩形，四周留 2–4 像素，不压到相邻的印刷字。
- 被印章、水印压住的签名：签名与印章各标一个框，允许重叠。
- 跨行、跨格的一个签名只标一个框；同一个人在一页上签了几处，就标几个框。
- 看不清是不是签名的笔迹（划线、勾选、涂改）：不标。
- 日期、诊断、检验结果等不需要脱敏的手写内容不标；如果误被遮盖，删掉那个框。
- 正文里的人名要区分身份：
  - 患者本人、家属、陪护、联系人标 `PERSON`；
  - 医生、护士、技师标 `STAFF`；
  - 只有姓氏的称呼（“李主任”）不标。

## 5. 质检

- 每批随机抽 10% 的页面由第二人独立标注。两人对同一目标的框交并比（IoU）≥ 0.7 算一致，类别也须一致。一致率低于 90% 的批次返工。
- 每批统计各类别数量。目标：签名、手写填写区、印章各 ≥ 3000 个实例；正文人名语料覆盖患者、家属、医护、机构四类。
- 常见问题记入本规范的附录，定期更新。

## 6. 标注员须知

- 上岗前签署保密协议。
- 不记录、不拍摄、不复述病案内容。
- 标注结束当天清理本机下载目录。
