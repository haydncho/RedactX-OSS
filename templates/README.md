# 常用表单模板

字段锚定的降级方案：OCR 没认出某个字段名（污渍、印章、折痕压住）时，按模板推算它的位置，照常遮盖其右侧的内容。

用本单位的空白或样例表单生成模板（只记录字段名与位置，不记录填写内容）：

```bash
.venv/bin/python -m redactx.detect.templates build 空白病案首页.pdf --name 住院病案首页
```

模板存为本目录下的 JSON（`*.json` 已加入 .gitignore，不会误提交）。容器里用 `REDACTX_TEMPLATES` 指定目录。
一页认出的字段名至少 3 个、且占模板字段名 40% 以上，并且位置能用缩放加平移对齐时才套用模板；版式不同的表单不会误套。
